\section{Supplementary Note 1: Hyperparameter sweep and bge-m3 model}

Supplementary Figure~\ref{fig:sweeps-e5} presents the cross-validated $R^2$ for all elastic net models reported in the main paper for different numbers of PCA components of the \emph{multilingual-e5-large} embeddings that are entered as predictors. \change{These results are based on a single (non-repeated, non-nested) \res{set.folds}-fold cross-validation run, as repeating the nested cross-validation for every number of components would have been computationally prohibitive. As the hyperparameters are selected on the same folds that are used for evaluation here, these $R^2$ values tend to be optimistic compared to the nested results in the main text \synthmismatch{(hardly in the APEQ data, but more clearly in the GCMQ data and especially in the comparatively small PTSD dataset)}; the informative part is therefore the comparison \emph{across} numbers of components. \synthmismatch{In the APEQ and GCMQ data, $R^2$ increases steeply up to about 10--15 components and remains largely stable up to about 40 components before slowly decreasing;} the \res{set.nprin} components used in the main analysis lie within this stable range. For PCL-5 in the PTSD data, the pattern is similar but noisier. For PTGI, no number of components leads to an increase over the baseline model.} Supplementary Figure~\ref{fig:sweeps-bge} presents the same information for the \emph{bge-m3} embeddings, where we find \synthmismatch{\change{comparable results, with one exception: for PCL-5, $R^2$ continues to increase up to 40--60 components, so that the main analysis with \res{set.nprin} components is, if anything, conservative here (although the gains at larger numbers of components, estimated on fewer than 210 training participants, are particularly prone to the optimism described above)}}. These results for the \emph{bge-m3} analysis are summarized in Supplementary Table~\ref{tab:results_summary_bge}, in the same format as Table~1 of the main text for the main  \emph{multilingual-e5-large} analysis.
